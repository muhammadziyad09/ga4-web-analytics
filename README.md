# GA4-Style Web Analytics

> **SAMPLE DATA / PORTFOLIO DEMONSTRATION ONLY**
>
> This project is built on sample data to demonstrate the service. It is not client work, and no client data is included or reused.

## Scope

- Sample GA4-style web analytics data covering 10 November–7 December 2025 (past 28 days in the source sample)
- Metrics covered in the source sample: users, conversions, conversion rate by Web and App, and engagement by Web and App
- Workbook structure in the source sample: Dashboard, Data, and Insights sheets
- Dashboard image in the source portfolio replicates GA4's card layout

## What was done

- GA4-style daily data cleaned with Python (pandas)
- Modelled in Excel with live-formula KPIs
- A written Insights sheet accompanying the dashboard

## Tools

Excel, Python (pandas), live-formula KPIs.
